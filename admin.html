WEDDING INVITATION

관리자 로그인

  1. console.firebase.google.com 접속 → 프로젝트 만들기
  2. 왼쪽 빌드 > Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3(서울)
  3. 왼쪽 빌드 > Authentication → 시작하기 → 이메일/비밀번호 사용 설정 → Users 탭 > 사용자 추가 로 관리자 계정 만들기
  4. ⚙️ 프로젝트 설정 > 내 앱 > </>(웹) 으로 앱 등록 → 나오는 firebaseConfig 코드 복사
  5. 아래에 붙여넣고 코드 만들기 → 만들어진 내용을 config.js 의 firebase 부분에 붙여넣고 커밋
  6. 마지막으로 Firestore 규칙 탭에 SETUP.md 의 보안 규칙을 붙여넣고 게시

아래 내용을 복사해서 저장소의 config.js 맨 위 firebase: { … } 부분과 통째로 바꿔주세요.
